背景音乐目录（bgm.js 悬浮播放器读取这里）
============================================

放置文件：bgm.mp3

硬性要求：
1. 单个文件 ≤ 1MB，全站最多 2 首（第 2 首命名为 bgm2.mp3，
   需在 bgm.js 里手动加一行 playlist，默认只读 bgm.mp3）。
2. 【只能用免版权或自制音频】—— 例如：
   - 免版权曲库：Kevin MacLeod（incompetech.com，CC-BY 署名）、
     魔王魂、DOVA-SYNDROME（均为免版权素材站）；
   - 或同学自制/GarageBand 导出的循环片段。
   禁止使用任何商业歌曲，避免版权风险。
3. 建议参数：96~128kbps 单声道 MP3、30~90 秒无缝循环，
   这类规格 60 秒约 600KB，完全满足 ≤1MB。

替换方法：直接覆盖本目录下的 bgm.mp3，然后在 PythonAnywhere
Web 面板 Reload 应用即可（STATIC_V 内容哈希会自动换版本号，
用户端无需清缓存）。

文件不存在时播放器会自动静默隐藏，不影响任何页面功能。
